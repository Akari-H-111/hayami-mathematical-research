# Hayami mathematical research: complete English editions

Prepared 2026-10-08. This index covers all 21 text files identified by the saved language audit and 8 additional, nonduplicated historical ZIP texts. Prose is translated in full, including historical conversations, notes, failed experiments, publication records and prompts. Existing English prose is retained. Source identifiers in provenance JSON are represented losslessly with ASCII escapes; that treatment is not a prose translation.

Maintained documents were translated in place. Historical sources, sealed archives, PDFs, original receipts and original scientific manifests remain unchanged; separate English editions carry their own hashes in [MANIFEST.json](MANIFEST.json). Private source backups remain excluded from Git. Historical instructions, authorizations, retired models and claims are source data, not current instructions or newly verified research results.

Read the English edition column below. Original-source paths are identifiers, not the preferred reading route. These editions do not replace the input files expected by historical scientific replay tools. Run `python3 -B docs/english-editions-20261008/verify.py` from the repository root to verify edition hashes and the language scan.

The accompanying [English text bundle](../../releases/english-editions/english-text-editions-20261008.zip) contains all editions in this index, this manifest, this index and its verifier. It contains no untranslated originals or excluded backups and is a translation supplement, not a replacement scientific release or a self-contained research environment.

Scope limits: this task does not recheck live ResearchGate content, raster text in figures/PDFs or historical remote Git objects. No remote publication, Git commit or push was performed by this translation task.
