# Geometry: four current papers

[All series](../README.md) · [Repository home](../../README.md)

There are three historical workstreams and **four current papers**. The old
Bicomplex preprint is succeeded by two papers; it is not a fifth current paper.
Read Ruled and Stokes before the Bicomplex successors for their shared geometry.

The directory name `legacy-geometry` is retained because reconstruction tools,
sealed receipts and existing links depend on it. It describes provenance,
not the maturity of the current papers. The [source registry](source-registry/SOURCE_REGISTRY.md)
separates final historical PDFs from ancestors and recovered source candidates.
Historical Ruled v4 and Bicomplex v12 claims must not be promoted wholesale to
current theorems. Use the current coverage maps in the [verification guide](../../verification/README.md).
