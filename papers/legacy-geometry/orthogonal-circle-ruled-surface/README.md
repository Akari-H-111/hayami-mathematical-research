## Historical reconstruction: v4


Source: `ruled-v4` in the source registry.

The 13-page final PDF is the authority for the paper's theorem labels and scope.  Its current reconstruction focus is the finite geometric/algebraic core: parametrization, non-developability, first fundamental form, regularity classification, the complex observation field, phase skeleton, topological dipole, fold locus, and local fold consequences.

`source_ancestor/` contains the latest located pre-final TeX (dated 2026-07-06) and all ten original figure assets. It rebuilds to 13-page A4. The portable ASCII word-token alignment is about 73 percent (a glyph-sensitive exploratory metric was about 61 percent), so it is an ancestor/source reservoir, not the v4 final source. Every copied formula still needs a PDF page reference and a fresh derivation.
